Constantes de dominio y UI. Sin lógica, solo valores estables.

| Carpeta | Contenido |
|---------|-----------|
| `brand/` | Colores, tipografía, nombre de producto |
| `roles/` | Roles ARTS y cuentas demo |
| `ui/` | Tamaños, z-index, labels genéricos |
| `coverage/` | Secciones de cobertura, tasas base, impuestos por país |
