# src/config/

Configuración de la aplicación: variables de entorno tipadas, mapa de rutas y navegación por rol.

| Archivo | Uso |
|---------|-----|
| `env.ts` | Lectura tipada de `process.env` |
| `routes.ts` | Constantes de paths (`/login`, `/producer/panel`, …) |
| `navigation.ts` | Ítems del sidebar por rol |
